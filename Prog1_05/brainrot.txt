3: Melyik Boss Karakter jelenik meg?

a) rész: SEGFAULT SAMU
Miért: Mert a kód egy null pointert (nullptr) próbál dereferenciálni (megnyitni), azaz a semmiben akar egy értékhez hozzáférni, amitől a program azonnal összeomlik.

b) rész: MEMORY LEAK MIKI
Miért: Mert a malloc() függvénnyel lefoglaltunk egy memóriaterületet, de elfelejtettük felszabadítani a free() paranccsal. A memória így lefoglalva marad, ami memóriaszivárgáshoz vezet.

c) rész: STACK OVERFLOW STAN
Miért: Mert a függvénynek nincs kilépési feltétele (base case), így végtelen rekurzióba lép. Önmagát hívogatja, amíg a hívási verem (call stack) teljesen meg nem telik, és a program össze nem omlik.

4: Saját Brainrot Karakter (Példa megoldás)

Név: Konstans Konrád
Fogalom: const kulcsszó
Személyiség: Egy rendíthetetlen, makacs figura, aki gyűlöli a változást. Ha egyszer értéket kap, azt az életben többet senki nem módosíthatja. Ha mégis megpróbálod megváltoztatni, a fordító azonnal rád kiabál.
Idézet: "Amilyen vagyok, olyan maradok. Ne próbálj megváltoztatni!"
Kódpélda:
const int konrad = 100;
konrad = 200; // Fordítási hiba, Konrád megváltoztathatatlan
